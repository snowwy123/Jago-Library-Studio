# Jago Library

A home for your creative projects.

Keep artwork, fonts and documents in one place. Link folders you already use, make reference boards, and turn selected assets into layouts in Production.

## Give it a try

Install with Jago Suite, or extract the portable download and open **Jago-Library.exe**.

Link a folder or add a few files. Make a collection or drop images onto a board. When you want to make a finished piece, take the artwork into Production.

[Find Jago Suite and downloads](https://jagosuite.co.uk/)
