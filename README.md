# Jago Library 0.10.4

A home for your creative projects.

Browse assets and fonts, organise projects, build reference boards and production layouts, and work with documents. Keep linked originals where you choose or collect verified copies deliberately.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Library-Studio/releases/latest)

## Get started

Download **Jago-Library-v0.10.4.zip**, right-click it and choose **Extract All**. Open **Jago-Library.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition. Open **Jago-Library.html** for offline browser use in current Edge or Chrome.

Windows requires 64-bit Windows and .NET Framework 4.8. Windows studio hosts require Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-Library-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- Asset search, tags, favourites, installed-font discovery and specimens.
- Production layouts, editable text, image frames, templates and contact sheets.
- PDF viewing, page tools, conversion to Word and local OCR options.
- Linked folders, nested collections and editable .jagolibrary projects.
- Cross-studio asset routes for artwork, textures, font specimens, audio and MIDI.
- Office previews and local PDF conversion for supported Word, slide and spreadsheet files.
- Live linked-source refresh, missing-file review and fingerprint-based relocation.
- Project health, duplicate checking, document revision comparison and export history.
- Reusable template shelf, portable .jagokit packages, briefs, brand kits and delivery profiles.
- Jago Board adds reference-canvas launch, auto-arrange, rectangle selection, snapping and sized exports.
- Production adds frame/content control and bounded trimmed video layers, overlays and short video exports.
- Capture inbox and selectable image-text OCR connect Companion assets to a project.
