# Library, Board & Production workflows

Library 0.12.0 development preview

## Find a saved studio project

Choose **Library → Jago projects**. Use the Studio selector to narrow the catalog. Search, tags, folders, favourites and collections still apply; the visible scope line explains your current location and filters. **Show all assets** clears those restrictions. Save the current search to return to the same project/studio filter later.

Project cards identify their studio. Covers are saved images, not an editable interpretation of the project. In Windows, **Open original [studio] project** uses the file's associated application. That application and association must be available; the browser edition cannot launch a local app. Sending a cover to another studio transfers artwork, not editable native layers. Existing projects without embedded covers can be opened and saved in their studio, or given a manual preview in Library.

**Folders & sources** opens the existing live-source and missing-file recovery tools. Linked originals stay where they are. Removing an entry never deletes the original. **Templates** opens your reusable design shelf.

## Collect references quickly

Select available images, saved covers or fonts and choose **Add to Board…** beside Use in Production. Pick a board in the current collection or give a new one a name. Library opens it as a focused board and arranges the incoming references beside existing items.

Focused Board keeps Add images, Fit, Arrange, Focus selection, Export image, Save project and Full Library nearby. More contains artboard framing, rename, paste, shortcut location and controls help. Arrange previews the result before applying and remembers spacing; the initial gap is eight board pixels. Full tools remain available. Board uses the existing 300-reference / 30-board limits.

Drag empty space to select; Shift adds. Wheel zooms at the pointer; Space + drag or middle mouse pans. **F** fits the board; **Shift+F** focuses the selection; **1** restores 100% zoom. Arrow keys nudge unlocked references; Shift nudges ten pixels. Ctrl+D duplicates; Ctrl+Z and Ctrl+Shift+Z undo/redo. Escape cancels a gesture without losing earlier redo history. Image elements are retained through selection and movement.

## Export the chosen area at higher resolution

Choose **Export image…**. Start with **All references · tightly cropped**, selected references, an optional artboard frame or the current view. Longest-edge resolution presets keep that area's proportions. Edit either pixel dimension with **Keep area proportions** enabled to update the other automatically. Uncheck it only to deliberately fit artwork into a different canvas shape.

Outer margin starts at zero. The preview matches the output proportions and displays available image thumbnails. Format, margin and transparency are remembered for the board. PNG/WebP support transparency; JPEG has a solid background. The Save button confirms exact dimensions and format and remains visible at narrow sizes. Closing an in-progress export or switching boards rejects its pending save.

[Board export and arrangement guide](Board-Export-and-Arrangement.md) covers artboard frames, compact previews, saved spacing, focus and stacking controls. Automatic recovery is a local safety copy; use Save project for portable editable work.

## Work in Production

Add artwork, Templates and Save as template are near the canvas, using the original controls. Image frame/content controls appear first in the selection inspector. The mode label tells you whether you are editing a frame or its contents; selecting another layer exits contents mode.

Export is the main finishing action. **Other export actions** contains video, artwork kits, multi-design ZIP and PDF routes. All-design export preserves each design's own canvas; mixed dimensions are explicitly labelled, with an expandable size list. It does not resize every design to the current design's dimensions. Board exports use their own dialog.

At narrow desktop widths, Folders & collections / Asset details and Layers & canvas / Selection controls open the relevant side panels. Close panel or Escape dismisses them. Wider windows keep the usual side-by-side panels. Theme button surfaces switch immediately with their text, avoiding low-contrast transitions between dark and light appearances.

## Offline and optional tools

Core browsing, boards and layouts remain offline. Existing Office/PDF/OCR engines remain optional; this focused portable preview does not bundle new engines or change their setup. The illustrated PDF guide covers the base tools; this guide describes the workflow refinements.
